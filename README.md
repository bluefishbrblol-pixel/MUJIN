# ユーザー検閲型匿名SNS 設計書 v14
**プロジェクト名: MUJIN（無尽）**
*アカウント不要・ユーザー自治・P2P分散型匿名SNS*

---

## 1. コンセプト

### 基本思想
- 運営が検閲しない
- ユーザーが集合知で秩序を作る
- 誰でも即座に参加できる
- 誰も管理者に依存しない

### 設計の本来目的
個人サイト・創作者のための送客インフラ。SNSはその手段。
AIクローラーのスクリーニングから逃げたい創作者層を守りつつ、閲覧者を増やす。

Twitterや YouTubeのように金で露出を買えない。広告枠がない。票は24時間で消える。運営は収益化できない。構造的に金が効かない場所。作品の質だけで勝負したいが、金の影響力に殴り勝てない創作者のための宣伝SNS。

### 設計の三原則
1. **匿名性** — アカウント不要、身元不明
2. **自治性** — ルールはユーザーが作り、ユーザーが更新する
3. **分散性** — 特定のサーバーに依存しない

## 2. タブ構成（三文化圏）

| タブ | 文化圏 | 入場条件 |
|------|--------|----------|
| 身内タブ | 創作・コミュニティ・長期滞在 | 票の消費（一回払い切り） |
| 観戦タブ | 実況・レスバトル・賭け | 無料 |
| 情報スレ | 創作者・個人サイト送客 | 無料 |

三タブは票という共通通貨で緩やかに繋がる。

### 身内タブの殿堂入り：コピペ図鑑
ウケた発言・造語・内輪ネタをコミュニティ投票で永続登録する。
テキストベースのミーム図鑑。コミュニティが生んだ文化の記録として残る。
情報スレが外に開く送客インフラなら、身内タブは内に閉じる文化の蓄積。

## 3. 基本機能

| 機能 | 仕様 |
|------|------|
| 投稿 | テキストのみ（最大500文字） |
| 存続期間 | 24時間で自動削除 |
| 識別子 | 国コード+番号（例: JP-#000042） |
| 投稿形式 | スレッド方式 |
| ブラックリスト | 個人単位での非表示設定 |

### スレッド設計
- 誰でも自由にスレを立てられる
- スレ主は匿名・無権限・立てたら一般ユーザーと同列
- スレの生死はコミュニティが決める
- 過疎スレは24時間で自然消滅
- 対立軸はスレ参加者全員が投票で調整できる

### 議題の供給源
外部APIやニュース自動取得は使わない。
ブラックリストと情報スレの殿堂入りURLそのものがコミュニティの議題になる。
ユーザーが選んだものだけが話題になる設計。

### 意図的に省いた機能
- 画像・動画投稿（法的リスク構造的排除）
- フォロー機能
- プロフィール
- DM・グループチャット
- 外部ニュース自動取得（ユーザー自治の原則と矛盾するため）

## 4. 投票権（票）システム

### 票は唯一の共通通貨
身内タブ入場・検閲投票・レスバトル・賭けの全てに同一の票を使用。

### 票の有効期限
票は24時間で消滅する。配らないと消える設計。
蓄財・権力の固定化を構造的に防ぐ。毎日使い切る動機が生まれる。

### 票の入手経路

| 方法 | 仕組み |
|------|--------|
| 発言抑制 | 連投しないほど票の重みが増す（狼少年システム） |
| 情報殿堂入り | 永続掲載により長期間いいねが積み上がる |
| レスバトル勝利 | 組織投票権を獲得 |
| 賭け勝利 | オッズ制で票が増える |
| 仕分け人への謝礼 | サンキューバック（後述） |

### 狼少年システム
連投頻度と投票権重みを全タブで連動させる。発言を増やすほど票の重みが下がる。
荒らしはブラックリスト入り。

## 5. ユーザー検閲システム

### ブラックリストの仕組み
```
1. ユーザーが特定ワード・投稿を通報
2. 通報数が閾値を超えると仮フィルター発動
3. 「一分間考察」議題として全ユーザーに提示
4. 投票により維持か解除かを決定
5. 結果をブラックリストに反映（永続データ）
```

### 一分間考察
- 主目的：通知によるエンゲージメント・習慣形成
- 投票期間：24時間
- 結果はオープンに公開

## 6. 情報スレ

### 概要
創作者・情報提供者が個人サイトへの送客導線として使うタブ。

### 殿堂入りリスト
- 個人サイトのURLと説明コメントを掲載可能
- 掲載は票の消費で申請→コミュニティ投票で確定
- 殿堂入り投稿のみ24時間削除の対象外（永続掲載）
- 金銭取引なし、匿名性を維持
- 図鑑の100枠をレスバトラー・コピペ・URLで共有する

### 仕分け人
殿堂入り候補の選別・議題化を担う役割。

**取得条件**
- 身内タブ入場済み（票を払った）
- レスバトラーでない

**権限の定義**
仕分け人は「門番」であり「王」ではない。
トレンドへの影響力ではなく、議題化できる作業回数への報酬設計とする。
印象操作の構造的リスクを認識した上で、作業権の付与に限定する。

**サンキューバック制度**
情報スレの受益者（創作者・閲覧者）が仕分け人の労働に対していいねや票を贈与できる。
稀に大量に返ってくる確率設計により、地味な役割を続けるインセンティブになる。
贈与された票は通常の票と同じ扱い（重みの操作なし）。

**仕分け人の罷免制度（免許点数制）**
```
通報されるたびに違反点数が加算
→ 一定点数で仕分け人資格停止（一時的）
→ さらに累積で資格永久剥奪
→ 身内タブ資格は別カウントで維持
```
罷免トリガーはブラックリスト投票と同一構造（一分間考察→コミュニティ投票）。

## 7. 観戦タブ

### 概要
実況・レスバトル・賭けが「観戦」という文脈で統合された文化圏。
スレッド単位で議題が立ち、コミュニティが自然に盛り上げる。

### 実況
スレッド内のリアルタイム投稿がそのまま実況になる。

### 賭けシステム
**オッズ制（報酬のみ・ペナルティなし）**
- 負け側を応援していた票が少ないほど、勝った時の票が増える
- オッズは数分おきに更新（リアルタイムではなく意図的な遅延）
- 更新タイミングを読んだオッズ操作が抜け穴として存在する
- 抜け穴を突いて票を稼ぐ成金層が生まれることを設計上許容する
- 締め切り直前の駆け込みで大逆転が起きる
- ペナルティなし → アカウント不要・匿名設計と無矛盾

賭け対象はユーザーがスレッドで自由に立てる。

### レスバトル興行

**自動検知条件（三条件AND）**
- 二者間のレス応酬が一定回数を超える
- 両者の投票権重みが低下し始めている
- 観客の票が一定値貯まっている

**図鑑登録・勾留フロー**
```
観客が「図鑑登録」ボタンを押す
→ 二者が「勾留」状態に
→ 当事者は気づかないまま口論継続
→ 受理／不受理／不起訴／焚き付けに分岐
```

**審理ステータス**
| ステータス | 内容 |
|-----------|------|
| 受理 | 審理開始 |
| 不受理 | 上告却下、終了 |
| 不起訴 | 興行認定しない |
| 棄却 | 一定時間内に票が集まらなければ自動終了 |
| 焚き付け | 判定を意図的に遅らせて当事者を煽る |

**三審制**
```
一審 → 二審（上告可） → 最高裁（上告可）
観客が控訴を棄却した場合はその限りではない
```

**勝敗判定**
観客投票 × 視聴数の倍率。盛り上がるほど勝者の報酬が増える。

**レスバトラーの権限**
勝利により検閲投票の再審理請求権（組織票）を獲得。
再審理が可決されて検閲が覆った場合、票は消費される。貴族化しない設計。

## 8. 図鑑システム（番号枠100）

### 概要
レスバトラーの戦績とコピペ図鑑への登録、殿堂入りURLを統合した番号制度。
100枠を巡ってレスバトラー・コピペ職人・創作者が争う。番号の来歴がそのままコンテンツになる。

### 番号の意味
- 低番号 → 創設者
- 戦績持ち → レスバトラーとして使った履歴
- ネタ持ち → コピペ図鑑として登録された履歴
- URL持ち → 殿堂入り個人サイトとして登録された履歴
- 同じ番号に複数の履歴が乗りうる

### 来歴の保存上限
各番号につき来歴は100件まで保存。古いものから順に消えていく。
歴史は忘れられるところまでが歴史。

### レスバトラー登録フロー
```
一般ユーザーが繰り返しレスバ自動判定を受ける
→ システムが「レスバトラーにならないか」と通知
→ 承諾すれば図鑑に登録・番号取得
→ 100人に達した時点で自動勧誘停止
```

### コピペ図鑑登録フロー
```
身内タブでウケた発言が投票でコピペ図鑑候補に上がる
→ コミュニティ投票で確定
→ 発言者に番号が付与される
```

### 番号の売買
売買・譲渡は自由。プラットフォームは関与しない。リスクは当事者が負う。
観戦タブで票を稼いだ成金層が番号を買い、何をするかがコンテンツになる。

### 100枠以降
MUJINが保存するミームは100個まで。100番を超えたものは個人サイトで育てる。
MUJINは種火を灯すだけ。その先は外の世界へ。

## 9. 役割の比較：レスバトラーと仕分け人

| 項目 | レスバトラー | 仕分け人 |
|------|------------|----------|
| 活動場所 | 観戦タブ | 情報スレ |
| 役割 | 対立・興行 | 選別・議題化 |
| 取得条件 | 自動検知→承諾 | 身内タブ入場済み・非レスバトラー |
| 制裁方式 | 免許点数制 | 免許点数制 |
| 番号 | 図鑑番号（100枠） | なし |
| 共通点 | やっていることは違うが、制裁構造と役割の有限性は同じ |

## 10. 法的設計

- テキストのみ → 児童ポルノリスクを構造的に排除
- P2P → 特定の管理者が存在しない
- 24時間削除 → 差し出すデータが存在しない
- オープンソース → 開発者はプロトコルの作者に過ぎない
- 金銭取引なし → 決済情報と匿名性の矛盾が発生しない
- 擬似ブックメーカー → 票建てのゲーム内ポイントであり賭博法の対象外
